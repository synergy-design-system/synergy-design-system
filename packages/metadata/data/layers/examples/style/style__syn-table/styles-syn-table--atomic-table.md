## Atomic Table

Create table styles using multiple classes attached to table, td and th elements.

```html
<table class="syn-table">
  <thead>
    <tr>
      <th class="syn-table-cell--header">Header content</th>
      <th class="syn-table-cell--header">Header content</th>
      <th class="syn-table-cell--header">Header content</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td class="syn-table-cell">Cell content</td>
      <td class="syn-table-cell">Cell content</td>
      <td class="syn-table-cell">Cell content</td>
    </tr>
    <tr>
      <td class="syn-table-cell">Cell content</td>
      <td class="syn-table-cell">Cell content</td>
      <td class="syn-table-cell">Cell content</td>
    </tr>
    <tr>
      <td class="syn-table-cell">Cell content</td>
      <td class="syn-table-cell">Cell content</td>
      <td class="syn-table-cell">Cell content</td>
    </tr>
    <tr>
      <td class="syn-table-cell">Cell content</td>
      <td class="syn-table-cell">Cell content</td>
      <td class="syn-table-cell">Cell content</td>
    </tr>
  </tbody>
</table>
```
