## Focus

The focus event gives the user feedback that the icon-button has been focused by the keyboard interaction.

```html
<div style="padding: 5px">
  <div
    style="align-items: center; display: flex; gap: var(--syn-spacing-large)"
  >
    <syn-icon-button
      name="wallpaper"
      label="Wallpaper"
      color="neutral"
      size="small"
    ></syn-icon-button>
    <syn-icon-button
      name="wallpaper"
      label="Wallpaper"
      color="neutral"
      size="medium"
    ></syn-icon-button>
    <syn-icon-button
      name="wallpaper"
      label="Wallpaper"
      color="neutral"
      size="large"
    ></syn-icon-button>
  </div>
</div>
```
