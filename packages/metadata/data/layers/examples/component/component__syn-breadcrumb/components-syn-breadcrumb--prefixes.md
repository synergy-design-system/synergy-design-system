## Prefixes

Use the prefix slot to add content before any breadcrumb item.

```html
<syn-breadcrumb>
  <syn-breadcrumb-item>
    <syn-icon slot="prefix" name="home"></syn-icon>
    Breadcrumb Item
  </syn-breadcrumb-item>
  <syn-breadcrumb-item>Breadcrumb Item</syn-breadcrumb-item>
  <syn-breadcrumb-item>Breadcrumb Item</syn-breadcrumb-item>
</syn-breadcrumb>
```
