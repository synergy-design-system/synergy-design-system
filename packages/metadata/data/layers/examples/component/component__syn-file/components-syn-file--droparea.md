## Droparea

Use the droparea attribute to switch to a full-width button with a drop area.

```html
<div
  style="display: flex; flex-direction: column; gap: var(--syn-spacing-large)"
>
  <syn-file
    accept="text/plain,image/*"
    droparea=""
    help-text="This is a help text"
    label="Small"
    multiple=""
    size="small"
  ></syn-file>
  <syn-file
    accept="text/plain,image/*"
    droparea=""
    help-text="This is a help text"
    label="Medium"
    multiple=""
    size="medium"
  ></syn-file>
  <syn-file
    accept="text/plain,image/*"
    droparea=""
    help-text="This is a help text"
    label="Large"
    multiple=""
    size="large"
  ></syn-file>
</div>
```
