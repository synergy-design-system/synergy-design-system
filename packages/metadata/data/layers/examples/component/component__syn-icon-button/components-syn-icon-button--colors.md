## Colors

The Icon button can have two color variants, Primary or Neutral Color.

```html
<div style="align-items: center; display: flex; gap: var(--syn-spacing-large)">
  <syn-icon-button
    name="wallpaper"
    label="Wallpaper"
    color="neutral"
    size="medium"
  ></syn-icon-button>
  <syn-icon-button
    name="wallpaper"
    label="Wallpaper"
    color="primary"
    size="medium"
  ></syn-icon-button>
</div>
```
