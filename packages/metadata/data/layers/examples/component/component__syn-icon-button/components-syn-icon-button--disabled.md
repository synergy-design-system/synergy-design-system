## Disabled

Use the disabled attribute to disable the icon button.

```html
<div style="align-items: center; display: flex; gap: var(--syn-spacing-large)">
  <syn-icon-button
    name="wallpaper"
    label="Wallpaper"
    color="neutral"
    disabled=""
    size="medium"
  ></syn-icon-button>
  <syn-icon-button
    name="wallpaper"
    label="Wallpaper"
    color="primary"
    disabled=""
    size="medium"
  ></syn-icon-button>
</div>
```
