## Contained

To give content more structure, you can use the property contained.

```html

  <syn-details open="">
    <span slot="summary">Accordion Element</span>
    <h3
      style="
        margin: 0 0 var(--syn-spacing-x-small);
        font: var(--syn-body-small-bold);
      "
    >
      Subheadline
    </h3>
```
